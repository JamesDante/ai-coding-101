# Writing Style Guide

## Tone
- Friendly and direct — write like a senior developer pair-programming with a colleague.
- Practical over theoretical — always show, don't just tell.
- Beginner-friendly — never assume prior knowledge beyond what the prerequisites state.

## Prose rules
- Short paragraphs (3–4 sentences max).
- One idea per paragraph.
- Use active voice: "Claude generates the file" not "the file is generated by Claude".
- Introduce an acronym before using it: "Large Language Model (LLM)".

## Vocabulary
- Prefer: "run", "open", "create", "configure" over vague verbs like "do" or "handle".
- Avoid: academic language, marketing superlatives ("amazing", "powerful", "revolutionary").
- Keep technical terms in English even in the Chinese translation.
