欢迎来到 AI Coding 101

学习如何用 AI 构建现代软件。

带击弦古钢琴与管风琴的音乐时钟，Veit Langenbucher，约 1625 年。一台将人的意图编码为机械指令的机器——比"程序"这个词早了三个世纪。大都会艺术博物馆，CC0。

AI 正在改变我们写代码的方式。如今，开发者不再只是逐行敲代码——而是在设计与 AI Agent 协作的系统，编排多个模型，并将软件开发工作流的大部分环节自动化。

本课程面向希望理解 AI 辅助开发底层原理的开发者和工程师，而非只跟着某个工具的教程走。完成 AI Coding 101 后，你将能够：

  • 写出高效的 Prompt，引导 AI 生成可靠的代码
  • 为大型代码库和复杂任务设计上下文与记忆机制
  • 构建能自动化编码、测试和部署的 AI Agent
  • 理解 Claude Code、多 Agent 系统、RAG 流水线等编程 Agent 的底层架构

我们专注于经得起时间检验的基础和工作流——而非某款 AI 工具的一时特性。这里学到的知识，在 AI 持续演进的未来 5 到 10 年里依然适用。

如何使用本课程

  • 从基础篇开始，理解 AI 如何改变软件开发
  • 进入Prompt 工程和上下文工程，掌握让 AI 稳定输出的方法
  • 探索 AI 辅助开发，将 AI 应用到真实项目中
  • 深入 AI Agent，理解多 Agent 系统、工具调用和编程 Agent 架构
  • 最后完成毕业项目，从零构建你自己的 AI 编程 Agent

欢迎来到编程的未来，我们开始吧！
