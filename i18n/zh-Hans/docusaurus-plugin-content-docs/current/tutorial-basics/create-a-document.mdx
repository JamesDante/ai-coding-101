# 创建文档

文档是通过以下方式连接的**页面集合**：

- **侧边栏**导航
- **上一页 / 下一页**跳转
- **版本管理**

## 创建第一个文档

在 `docs/hello.md` 新建一个 Markdown 文件：

```md title="docs/hello.md"
# 你好

这是我的**第一篇 Docusaurus 文档**！
```

新文档现在可以通过 [http://localhost:3000/docs/hello](http://localhost:3000/docs/hello) 访问。

## 配置侧边栏

Docusaurus 会自动根据 `docs` 目录**生成侧边栏**。

通过 Front Matter 自定义侧边栏标签和排序：

```md title="docs/hello.md" {1-4}
---
sidebar_label: '嗨！'
sidebar_position: 3
---

# 你好

这是我的**第一篇 Docusaurus 文档**！
```

也可以在 `sidebars.js` 中手动配置侧边栏结构：

```js title="sidebars.js"
export default {
  tutorialSidebar: [
    'intro',
    // highlight-next-line
    'hello',
    {
      type: 'category',
      label: '教程',
      items: ['tutorial-basics/create-a-document'],
    },
  ],
};
```
