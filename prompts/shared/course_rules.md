# Course Rules

## Target audience
Developers who write code daily but have little or no experience with AI-assisted workflows.

## Assumed knowledge
- Basic command-line usage (cd, ls, mkdir)
- Familiarity with at least one programming language
- Understanding of what an API is

## Do NOT assume
- Prior experience with LLMs or AI tools
- Python knowledge (use Python only where explicitly required by the spec)
- Paid API access — always show free-tier or trial paths where available

## Pacing
- Total course duration: ~5 hours of hands-on work
- Each chapter: 15–30 minutes
- Every chapter must be completable independently (no hidden state from previous chapters)

## Consistency
- Refer to the AI assistant as "Claude" throughout, not "the model" or "the AI"
- Use macOS/Linux terminal syntax; add a note for Windows where commands differ
