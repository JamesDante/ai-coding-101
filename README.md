## What is This?

**AI Coding 101** is an open-source, bilingual (EN + ZH) tutorial site for developers learning to work with AI coding assistants. It covers the full arc from writing better prompts to building production-grade AI agents.

The site is built with [Docusaurus](https://docusaurus.io/). All course content is generated by a **multi-agent AI pipeline** that takes a structured outline and produces publication-ready MDX documentation in English and Chinese — including code examples, admonitions, and a full review-and-fix pass.

**Live site:** [jamesdante.github.io/ai-coding-101](https://jamesdante.github.io/ai-coding-101/)

## AI Doc-Generation Pipeline

The `scripts/` folder contains a multi-agent pipeline that turns `scripts/outline.md` into fully written Docusaurus MDX docs (English + Chinese).

```
Curriculum Agent
      ↓
  Spec Agent          ← determines structure, sections, and code examples per chapter
      ↓
  Writer Agent        ← generates EN doc + ZH translation
      ↓
  Sidebar Builder     ← writes _category_.json + sidebars.ts
      ↓
  Reviewer Agent      ← scores each chapter across 8 weighted dimensions
      ↓
  Fixer Agent         ← patches flagged issues
      ↓
  Reviewer Agent      ← re-reviews fixed chapters to verify quality
```

### Setup

```bash
cd scripts
pip install -r requirements.txt
```

Create a `.env` file in `scripts/` (or the repo root):

```env
# Anthropic (default)
ANTHROPIC_API_KEY=sk-ant-...

# Local Ollama (optional)
# LLM_PROVIDER=ollama
# OLLAMA_BASE_URL=http://localhost:11434/v1
```

### Run the full pipeline

```bash
cd scripts
python generate_site.py --outline outline.md
```

### Common options

| Flag | Description |
|---|---|
| `--chapters 1` | Generate chapter 1 only |
| `--chapters 1-3` | Generate chapters 1 through 3 |
| `--chapters 1,3,5` | Generate specific chapters |
| `--chapters 1-3,5` | Mix of range and individual |
| `--resume` | Skip stages already completed (checkpoint resume) |
| `--skip-review` | Skip Reviewer + Fixer agents |
| `--review-only` | Only run Reviewer + Fixer on existing docs |
| `--no-fix` | Review but don't apply fixes |
| `--provider ollama` | Use local Ollama instead of Anthropic |
| `--ollama-model qwen2.5-coder:7b` | Override the Ollama model |

```bash
# Try it out: generate just the first chapter
python generate_site.py --outline outline.md --chapters 1 --skip-review

# Resume a partial run from where it left off
python generate_site.py --outline outline.md --resume

# Re-review and fix already-written docs
python generate_site.py --review-only

# Use local Ollama
python generate_site.py --outline outline.md --provider ollama --ollama-model llama3.1:8b
```

### LLM Providers

**Anthropic** (default) — set `ANTHROPIC_API_KEY`.

| Role | Model |
|---|---|
| Curriculum + Spec planner | `claude-opus-4-8` |
| Writer + Fixer | `claude-sonnet-4-6` |
| Reviewer | `claude-sonnet-4-6` |

**Ollama** (local) — set `LLM_PROVIDER=ollama` and run `ollama serve`.

```bash
ollama pull llama3.1:8b
python generate_site.py --outline outline.md --provider ollama
```

Override individual model slots:

```env
OLLAMA_PLANNER_MODEL=llama3.1:70b
OLLAMA_WRITER_MODEL=qwen2.5-coder:7b
OLLAMA_REVIEWER_MODEL=llama3.1:8b
```

### Checkpoint / resume

Every stage writes output to `scripts/output/`:

```
scripts/output/
  curriculum.json      # full course structure
  specs/               # one JSON spec per chapter
  review/              # reviewer scores + issues
```

Re-running with `--resume` skips any stage whose output file already exists.

### Customising the outline

Edit `scripts/outline.md` to define your own course. The Curriculum Agent reads it and produces `curriculum.json`; all downstream agents derive from that. Any standard Markdown structure works — `##` headings become chapters.

## AI 文档生成流水线

`scripts/` 目录包含一套多 Agent 流水线，将 `scripts/outline.md` 转化为完整的 Docusaurus MDX 文档（中英双语）。

```
Curriculum Agent（课程规划）
      ↓
  Spec Agent          ← 确定每章的结构、章节和代码示例
      ↓
  Writer Agent        ← 生成英文文档 + 中文翻译
      ↓
  Sidebar Builder     ← 写入 _category_.json + sidebars.ts
      ↓
  Reviewer Agent      ← 按 8 个加权维度对每章打分
      ↓
  Fixer Agent         ← 修复标记的问题
      ↓
  Reviewer Agent      ← 对修复后的章节再次审校
```

### 配置

```bash
cd scripts
pip install -r requirements.txt
```

在 `scripts/` 目录（或仓库根目录）创建 `.env` 文件：

```env
# Anthropic（默认）
ANTHROPIC_API_KEY=sk-ant-...

# 本地 Ollama（可选）
# LLM_PROVIDER=ollama
# OLLAMA_BASE_URL=http://localhost:11434/v1
```

### 运行完整流水线

```bash
cd scripts
python generate_site.py --outline outline.md
```

### 常用参数

| 参数 | 说明 |
|---|---|
| `--chapters 1` | 只生成第 1 章 |
| `--chapters 1-3` | 生成第 1 至 3 章 |
| `--chapters 1,3,5` | 生成指定章节 |
| `--chapters 1-3,5` | 范围与单章混合 |
| `--resume` | 跳过已完成的阶段（断点续跑） |
| `--skip-review` | 跳过审校与修复 |
| `--review-only` | 只对已有文档执行审校与修复 |
| `--no-fix` | 仅审校，不修复 |
| `--provider ollama` | 使用本地 Ollama 替代 Anthropic |
| `--ollama-model qwen2.5-coder:7b` | 指定 Ollama 模型 |

```bash
# 快速体验：只生成第 1 章，跳过审校
python generate_site.py --outline outline.md --chapters 1 --skip-review

# 从上次中断处继续
python generate_site.py --outline outline.md --resume

# 对已有文档重新审校并修复
python generate_site.py --review-only

# 使用本地 Ollama
python generate_site.py --outline outline.md --provider ollama --ollama-model llama3.1:8b
```

### LLM 提供商

**Anthropic**（默认）— 设置 `ANTHROPIC_API_KEY`。

| 角色 | 模型 |
|---|---|
| 课程规划 + Spec | `claude-opus-4-8` |
| Writer + Fixer | `claude-sonnet-4-6` |
| Reviewer | `claude-sonnet-4-6` |

**Ollama**（本地）— 设置 `LLM_PROVIDER=ollama` 并运行 `ollama serve`。

```bash
ollama pull llama3.1:8b
python generate_site.py --outline outline.md --provider ollama
```

各阶段模型可独立覆盖：

```env
OLLAMA_PLANNER_MODEL=llama3.1:70b
OLLAMA_WRITER_MODEL=qwen2.5-coder:7b
OLLAMA_REVIEWER_MODEL=llama3.1:8b
```

### 断点续跑

每个阶段的输出写入 `scripts/output/`：

```
scripts/output/
  curriculum.json      # 完整课程结构
  specs/               # 每章一个 JSON spec 文件
  review/              # 审校分数与问题列表
```

加 `--resume` 运行时，已有输出文件的阶段会自动跳过。

### 自定义大纲

编辑 `scripts/outline.md` 来定义自己的课程。Curriculum Agent 读取大纲并生成 `curriculum.json`，后续所有 Agent 都以此为基础。标准 Markdown 结构即可，`##` 标题对应章节。
